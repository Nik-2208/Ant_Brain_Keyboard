# Contributing to ANT BRAIN

Thank you for your interest in contributing to **ANT BRAIN**!

## Original Authorship & Attribution Notice

**ANT BRAIN** was originally conceived, designed, engineered, and developed by **Nikhilesh H. Chavda**.

Contributions from external developers, researchers, and engineers are welcome. All merged contributions will be credited appropriately in release notes and commit logs. Note that contributions do not alter the historical status of Nikhilesh H. Chavda as the original creator and primary author of ANT BRAIN.

---

## How to Contribute

1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/amazing-feature`).
2. **Commit Your Changes**: Follow clear commit messages (`git commit -m 'Add amazing feature'`).
3. **Open a Pull Request**: Provide a detailed description of your changes and test results.

---

## Code of Conduct & Standards

- Maintain clear documentation, comments, and scientific disclaimers.
- Respect all third-party software licenses and credits.
- Ensure new features pass local verification and syntax checks (`node -c app.js`, Python execution).
